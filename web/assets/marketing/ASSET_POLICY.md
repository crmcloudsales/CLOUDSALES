# CloudSales Marketing Asset Policy — STRICT CANONICAL LOCK

Only existing, approved, official brand assets may be used.

## Absolute rules

- NEVER generate, synthesize, redraw, reinterpret, approximate, recolor, restyle or replace a CloudSales logo, isotype, wordmark, Cloudy, AgentCloud or other protected brand asset.
- NEVER recreate the CloudSales wordmark with text, CSS, fonts, gradients or AI and present it as the logo.
- NEVER derive a new logo/isotype format from an existing raster asset unless a separately approved official source file already exists for that format.
- If a destination requires a format that CloudSales does not have as an approved official asset, BLOCK that release or omit the asset. Do not manufacture a substitute.
- Provider watermarks or third-party branding are prohibited on acquisition, marketing, lifecycle, welcome/access and other trust-sensitive CloudSales communications.
