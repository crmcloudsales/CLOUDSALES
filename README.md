# CloudSales

AI-operated Business Management Platform.

CloudSales is the mobile control layer for business operations. Cloudy and AgentCloud orchestrate marketing and sales tasks across connected systems while infrastructure such as HighLevel, Supabase, Cloudflare and provider APIs remains behind the experience.

## Launch principle

Connect -> Protect -> Capture -> Follow up -> Sell -> Feed signals back.

## Repository status

This repository is the canonical source of truth for CloudSales application and infrastructure code. Production recovery/versioning is in progress.
