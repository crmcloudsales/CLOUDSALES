# Canonical Directive Change Control

Any change to a canonical directive requires a new explicit user instruction that clearly changes the prior directive.

For provider/payment changes, the change record must identify:
- previous provider,
- new provider,
- explicit user instruction authorizing the change,
- effective date,
- affected plans/routes,
- verification evidence after deployment.

Automations, agents, models, CI jobs, existing integrations, convenience, legacy code, or provider availability are not valid authorization to change a canonical directive.
